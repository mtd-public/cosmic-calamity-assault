Settings

Good to know

  • Saves stay in this browser (IndexedDB): save from the menu or with F6; the game also autosaves after each objective. Clearing site data deletes them.
  • Controllers: any pad the browser sees (Xbox, PlayStation, Switch Pro), using the Xbox layout above. Press a button once if it isn't detected.
  • Mouse: the game captures the mouse while you play and frees it in menus. If it doesn't, click the game.
  • Fullscreen: Esc opens the game menu; hold Esc to leave fullscreen.
  • Needs Chrome or Edge 137+ (WebAssembly JSPI, WebGL2) on a desktop or laptop, and ~70 MB the first time. Sound is stereo only.
  • The browser build is GZDoom 4.11 (the desktop game targets 4.14). For the best experience, play the .pk3 in GZDoom.
The engine is GZDoom 4.11.3 compiled to WebAssembly by tomb-engine, free software under the GNU GPL v3; this page's harness (engine.worker.js, play.js) is adapted from it under the same license, and the build notes are in the repository. The base game is Freedoom: Phase 2 (BSD license).
