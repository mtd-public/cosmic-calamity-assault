; MAP05 "Crash Site" (GAME_DESIGN.md §9)
; Flow: the road in -> the overrun Army cordon (tents, trucks, floodlights, watchtower; plasma SMG in
; the armory tent) -> command tent (RED card: the wounded major, or the map table) -> red gatehouse
; -> forest ridge terraces (z 0 / 64 / 128 / 192; Harvester blade in the ranger cabin) -> the ridge
; top over the impact trench -> cut steps (or a drop) down into the trench (z -32) -> the breach in
; the saucer's hull -> ring corridor, engine room (Overseer, BLUE glyph), hold -> glyph door -> ramp
; up into the cockpit (z 96: the Singularity + the navigation shard, obj 1) -> hatch lift out to the
; far bank -> exit.
; Secrets: the west-woods cave, the cabin store room, a hull panel in the saucer's ring.
